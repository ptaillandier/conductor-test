# Règles de simulation GAMA
- Pour tester toute modification du modèle `.gaml`, exécute GAMA en mode headless via le terminal :
  `/Applications/Gama old release.app/Contents/headless/gama-headless.sh -m 2048m plan.xml results/`
- Lis ensuite le fichier XML/CSV généré dans `results/` pour vérifier qu'il n'y a aucune erreur de compilation ou d'exécution avant de commiter sur GitHub.
